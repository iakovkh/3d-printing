# Original request

Пользователь хочет создать 3D-модель брелка в форме объёмного зонтика для Гамбурга.

Исходные требования из диалога:
- брелок должен быть именно объёмным 3D-зонтиком, не плоской формой;
- надпись на зонтике: `Schietwetter`;
- стиль надписи: туристический;
- ширина купола: 45 мм;
- крепление для кольца: отдельное вынесенное ушко сверху зонтика;
- брелок должен быть удобным, классического размера;
- пользователь одобрил художественный концепт и отдельно потребовал, чтобы итоговая 3D-модель не расходилась с утверждённым концептом.
