# 3D Printing Cloud Workflow

Этот репозиторий хранит утверждённый процесс создания проверяемых 3D-моделей и результаты, которые можно получить через Codex Cloud с телефона без включённого домашнего компьютера.

## Обязательные документы

- [Правила для агента](AGENTS.md)
- [Утверждённый контракт](00_PROJECT_INSTRUCTIONS.md)
- [Последовательность от запроса до 3MF](01_CLOUD_WORKFLOW.md)

Перед моделированием Codex обязан прочитать эти документы. Они требуют подтвердить ТЗ, а для органических или декоративных моделей — отдельно подтвердить маркированный концепт. Кандидат затем повторно открывается, проходит геометрический QA и получает проверочные изображения, версию и SHA-ID.

## Работа с телефона

1. Подключите `iakovkh/3d-printing` как репозиторий Codex Cloud.
2. Создайте новую задачу в отдельной ветке и опишите модель текстом, голосом или фотографиями.
3. Подтвердите карточку ТЗ; до подтверждения геометрия не создаётся.
4. Просмотрите технические изображения из повторно открытого `candidate.3mf` и предупреждения QA.
5. Для выпуска напишите точное утверждение вида `Утверждаю <model> v003, ID 8F21C4A9`.
6. После проверок объедините pull request и скачайте `projects/<project>/05_release/vNNN/<name>_vNNN_geometry.3mf`.
7. Откройте 3MF в Anycubic Slicer Next, назначьте профиль, материал, цвета и поддержки, проверьте слои и отправьте на Anycubic Kobra S1 Combo.

`geometry.3mf` содержит проверенную геометрию и структуру частей, но не обещает готовый или проверенный профиль слайсера.

## Облачная среда

Репозиторий устанавливает Linux-инструменты командой `bash toolchain/setup_cloud.sh`. Среда включает CadQuery/OpenSCAD для точных моделей, headless Blender для органических моделей и общий набор проверок 3MF. Локальная Windows-копия Blender в GitHub не загружается.

## Версии и бинарные файлы

Показанные каталоги `vNNN` не перезаписываются. Git хранит историю обсуждения и изменений, но не заменяет версию файла, SHA-256 и явное утверждение. Крупные `.blend`, `.stl`, `.step` и `.stp` хранятся через Git LFS; готовые `.3mf`, QA и компактные PNG остаются обычными файлами Git для удобного просмотра и скачивания.
